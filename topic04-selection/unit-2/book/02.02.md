# Conditional statements and logical operators


In this step, we will implement another example from your lecture. 

Functionality:

- If the age is

    - < 4 Baby

    - < 13- Child

    - < 19 – Teenager

    - Otherwise Adult



## Class Exercise 2

In Project **Week4-Class-Exercises**, create a class called IfStatementsExample2 (avoid the temptation to copy and paste it...you learn more by writing the code out):

~~~java
        public static void main(String[] args) {
        int age = 10;
        if (age <= 3) {
            System.out.println("Baby");
        }
        else if (age > 3 && age <= 12) {
            System.out.println("Child");
        }
        else if (age > 12 && age <= 19) {
            System.out.println("Teenager");
        }
        else {
            System.out.println("Adult");
        }
    }
~~~
