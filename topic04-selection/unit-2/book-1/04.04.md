# Conditional statements  - grading system

## Class Exercise 4- Grading System

In Project **Week4-Class-Exercises**, create a class called GradeExampleExercise, which has a main method (avoid the temptation to copy and paste it...you learn more by writing the code out):

~~~java

    public static void main(String[] args) {
        int mark = 72;
        if (mark >= 60) {
            System.out.println("Second Class Grade 1");
        } else if (mark >= 70) {
            System.out.println("First Class");
        } else if (mark >= 50) {
            System.out.println("Second Class Grade 2");
        } else {
            System.out.println("Fail");
        }
    }

~~~

The above code has a logic error, student got 72 so it should print First Class, does it?Can you fix it?
