Logical operators: && (AND), || (OR), ! (NOT).

## Class Exercises 5- Driving license check:

In Project **Week4-Class-Exercises**, create a class called DrivingLicense, which has a main method (avoid the temptation to copy and paste it...you learn more by writing the code out):

~~~java
public static void main(String[] args) {
        int age = 20;
        boolean hasLicense = true;

        if (age >= 18 && hasLicense) {
            System.out.println("You can drive!");
        } else {
            System.out.println("You cannot drive.");
        }

    }

~~~

Can all people over 18 drive?  No, only those that have a license.  Play with the variables and see what happens when you change hasLicense to false.
