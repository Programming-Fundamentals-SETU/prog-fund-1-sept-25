# 4. ShopV2.2 - Implementing Validation
For this challenge, you will implement validation for the ShopV2.2 solution.

The validation should be implemented in the Product class.

The validation rules are as follows: 

- `productName` must be a non-empty String with a maximum length of 20 characters
- `productCode` must be a non-negative integer
- `unitCost` must be a  double between 1000 and 5000 (inclusive)
- `inCurrentProductLine` must be a boolean. (no validation required for this field).

These should be implemented in the `setProductName()`, `setProductCode()`, `setUnitCost()` and constructor methods.

- Try to reuse the setters in the constructor when possible.
- This will not be possible for the setting of the productName, so you will need to use an if-else statement to validate the length of the productName.
- You can use the `length()` method to check the length of the String.
- remember there is no else in setters.
