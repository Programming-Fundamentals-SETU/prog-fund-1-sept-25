Output Examples
HelloWorld            Print hello and welcome text using println
PrintText             Print lines of text using print and println, introduce \n
PrintFormatted        Print lines of text using printf and formatters

Input Examples
AddNumbers            Request two numbers, add them and print the sum
CompareNumbers        Request two numbers, compare for equality and relationship 

NumberSquared         Square a number
NumberSquaredNoZero   Square a number but check if zero first

OddEven               Determine if a number is odd or even
NumberBases           Demonstrate different number bases: Decimal, Octal, Hexadecimal.

Challenge #2
FindMax               Find maximum of two integers (see Challenge description)

SlidesExampleMix      A wild mixture of examples from Java Introduction slides
