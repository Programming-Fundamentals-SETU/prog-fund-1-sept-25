BENUTZERHINWEISE:

Die Schüler bekommen den Ordner "Hangman Projekt Vorlage für SuS", der Hangman_Muster.java nicht enthält.
Darin befinden sich nur Hangman.java als Worked-Example-Variante
und die SpielManager-Klasse, welche das Zeichnen des Fensters und kompliziertere Funktionen übernimmt.

SpielManager versucht, Bilddateien mit dem übergebenen Pfad passend einzubinden.
Die Bilddateien können von den Schülern durch neue Bilder mit beliebiger Auflösung ersetzt werden.
Die Wörter stammen aus "Wortliste.txt", welche angepasst werden kann oder es kann im Code auf eine andere Datei verwiesen werden.
Der SpielManager ist vielleicht etwas umständlich umgesetzt, aber er funktioniert.
