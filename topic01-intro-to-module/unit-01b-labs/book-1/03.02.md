# Opening the BlueJ (Processing Development Environment)

## If you are using the College Computers...

Go to the search bar at the bottom row of the screen. Type in **BlueJ**. This should bring up the app for you. Double click on it to open the BlueJ app. 


## If you are using your own computer...


## Using Windows. - TODO CHANGE IMAGE
Go to the directory/folder where you installed your BlueJ app.  


### Opening BlueJ

Now that you have nagivated to where BlueJ is installed, you should see a list of files and folders similiar to the picture below:

![BlueJ  Environment files](./img/04a.png)

(This is a screen shot using a MacBook - if you are using a labtop move the BlueJ file/icon to a similar folder e.g. dev if you have not already done so.)

Double click in the **BlueJ** application (highlighted by the red rectangle).

The BlueJ application should launch.

![The BlueJ Development Environment](./img/05.png)

## Using Mac Os X

Your BlueJ app should be in your Applications folder.  
![The BlueJ application (Mac)](./img/04b.png)

Double click on it to open the BlueJ app and it should launch.
![Opening screen](./img/05.png)
