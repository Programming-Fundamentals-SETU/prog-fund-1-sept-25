# Challenges

- For each challenge listed below, create a new class.

- These are quite 'challenging', so don't worry if you can't do them, but try to think about the code before you look at the solutions


## Challenge  1 (Even or Odd Checker)

Create a new class called **ChalExercise1**

**Description:**
Write a program that asks the user to enter 5 integers, one at a time.
For each number entered:

- Use an if statement to check if it’s even or odd.

- Print a message such as:

~~~
12 is even
7 is odd
~~~

**Hints:**

- Use a for loop to repeat 5 times.

- Use Scanner to read input.

- Use % 2 to check even/odd.

**Bonus:** Count how many even numbers were entered and print the total at the end.

## Challenge 2 (Guess the Secret Number)

Create a new class called **ChalExercise2**
**Description:**
- Pick a secret number between 1 and 50 (hard-coded in the program).
- Ask the user to guess the number.

- If the guess is too high, print "Too high!".

- If the guess is too low, print "Too low!".

- Keep asking until they guess correctly, then print "You got it!".

**Hints:**

Use a while loop that runs until the guess equals the secret number.

Use if statements to give feedback.

Use Scanner for each guess.

**Bonus:** Count how many guesses it took and display at the end.

## Challenge 3 (Class Scores)

Create a new class called **ChalExercise3**

**Description:**
- Ask the user how many students are in the class.
- Then, use a loop to input each student’s score (0–100).
- For each score:

    - If it’s 50 or above, print "Pass".

    - Otherwise, print "Fail".

- After all scores are entered, print the average score for the class.

**Hints:**

Use a for loop that runs based on the number entered.

Use a running total variable to calculate the average.

Use Scanner to read both the number of students and the scores.

**Bonus:** Count and print the number of students who passed.
