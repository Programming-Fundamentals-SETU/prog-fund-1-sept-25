# Variable scope (local and global)

In this step, we will implement the code examples from your lectures.


## Understanding variable scope

Create a new Project and call it **Week5-Exercises**. Create a class called **ScopeExample**

Enter the following code into your class (one again, try avoid the temptation to cut and paste the code...the more mistakes you make when writing out code, the more you learn!):

~~~java
public class ScopeExample {
    public static void main(String[] args) {
        int myAge = 21;
        
        if (myAge >= 18) {
             String details = myAge + " years old - Get ready to vote";
        }
        else{
             String details = myAge + " years old - Ah you can't vote yet!";

        }
        System.out.println(details);
    }

}

~~~

Is it compiling?  No, why?? 

- The details variable is not in scope.


To fix this, change your code so that the details variable has method scope: 

~~~java
public class ScopeExample {
    public static void main(String[] args) {
        int myAge = 21;
        String details;
        if (myAge >= 18) {
             details = myAge + " years old - Get ready to vote";
        }
        else{
             details = myAge + " years old - Ah you can't vote yet!";

        }
        System.out.println(details);
    }

}
~~~

Could you think of a different way to fix it??  How about?

~~~java
public class ScopeExample {
    public static void main(String[] args) {
        int myAge = 21;
        
        if (myAge >= 18) {
             String details = myAge + " years old - Get ready to vote";
             System.out.println(details);
        }
        else{
             String details = myAge + " years old - Ah you can't vote yet!";
             System.out.println(details);

        }
        
    }

}
~~~

Is this a better way?  What do you think?  (the answer to this is subjective, I don't think its better, but if it makes more sense to you then thats the way you should do it)
