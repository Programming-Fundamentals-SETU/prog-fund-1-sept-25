## Accessor and Mutator methods

In Java, accessor methods (also called getters) are used to return the value of a field without changing it. They “access” the information stored inside an object. For example, a getPrice() method will return the price of the ticket.
Mutator methods (also called setters) are used to change the value of a field. For example, a setPrice(int price) method can update the tickets price. Using accessors and mutators is good practice because it keeps fields private and allows the class to control how its data is read or modified.
