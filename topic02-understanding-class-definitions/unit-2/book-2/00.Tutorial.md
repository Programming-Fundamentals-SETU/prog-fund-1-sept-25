#  Tutorial

Fields · constructors · if statements

These exercises show you how to use fields, constructors, and if statements to create a program.
They should be completed on paper (using pen and paper) unless you would prefer to use a (non-BlueJ or other IDE) text editor.

The aim of the tutorials is to help you practice new concepts and get a feel for how any new concepts will work.
