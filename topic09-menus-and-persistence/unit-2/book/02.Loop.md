## SimpleWhile Exercise

Perform these steps:

- In BlueJ, create a new Project called **LoopExercises**.

- Create a class in this Project called **Loops**.   In this class, add the following code:

~~~
public class Loops {

    

    public String simpleWhile() {

        String s="";
        int i = 1;
        while (i <= 10){
            s += ", " + i;
            i++;
        }
        return s;
    }
}
~~~

- Create a class in this Project called **Driver**.   In this class, add the following code:

~~~
import java.util.Scanner;


public class Driver
{
    Loops loops = new Loops();
    
    public static void main(String args[]){
                new Driver();
    }
    
    public Driver(){
        System.out.println(loops.simpleWhile());
    }
}
~~~

This method, simpleWhile, will print out 1 to 10 to the console.  Does it look good?  Why is it printing a comma before 1, could you make it look nicer?  How about changing the loop to the following..

~~~
while (i <= 10){
    if (i ==1)
        s +=  i;
    else
        s += ", " + i;
        i++;
}
~~~
