Designed as Repetition of char- and string-arrays, for- and while-loops and if-statements without discussing OOP.
It is a worked-example, so students get detailled instructions in the code and are lead by a work sheet with documentation.
Afterwards motivated students can create their own hangman-images.

**Level:** Beginners / Intermediate (9th/10th grade)

**Duration:** 2-3 lessons

**Teaches:** Repetition of char- and string-arrays, for- and while-loops and if-statements without discussing OOP.
