# Exploring Behaviour of a Naive Ticket Machine

## Exercise 1 - Declare Variables

Write a Java class called **Person** in a program where you declare fields for:

- your age

- your first name

- today’s temperature (non-integer)

Use correct naming conventions (camelCase).

Try declaring one incorrectly (e.g., Int age;) and observe BlueJ’s error.
