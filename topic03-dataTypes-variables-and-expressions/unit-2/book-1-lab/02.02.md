# Exploring Behaviour of new  **Person** Class

**Advice**  
1. Once you have written and compiled each of the new methods etc. play with BlueJ to see how the methods work etc. 

2. For each of the exercises, write the code in the previously written class. SO you will have one class with all the methods on completing the exercises. 

## Exercise 1 - Declare Variables

Write a Java class called **Person** in a program where you declare fields for:

- your first name. It should be a String.

- your last name. It should be a String.

- your age. It should be an integer.

- today’s temperature (non-integer)

Use correct naming conventions (camelCase).

Try declaring one incorrectly (e.g., Int age;) and observe BlueJ’s error.

## Exercise 2 - Constructors

Write a constructor for the **Person** class (that you have written above) that takes a first name, a second name,  and an age as parameters.

## Exercise 3 - getters and setters

Write getters and setters for the **Person** class. This will entail writing 4 getters and 4 setters. 

## Exercise 4 - Methods

Write methods for the **Person** class that:

- 

- print your first name (call it printFirstname())

- print your full name (call it printFullName())

- print your age (call it printAge())

- print your temperature (call it printTemperature())


## Exercise 5 - Birthday

Write a method called **happyBirthday()** that increments the age by one. This should have a header like this:

~~~
public int happyBirthday() {
    // code here
}
~~~

This method should return the old age value and also increment the age by one.

**Hint:** You should use a local variable. 

## Exercise 6 - main method

Up to now we have used the BlueJ IDE to 'play' with the code. However, in a real program you will need to write a main method. 

Write a main method for the **Person** class that: 

- creates a new Person object called **me** (with values of your own)

- prints the full name of the **me** object
- prints the age of the **me** object

- calls the happyBirthday() method on the **me** object and prints something like this: "Happy Birthday! You were 20 years old. You are now 21 years old." 

**Hint:** 

- Use the return value of the happyBirthday() method as the old age value, which you can use in the output string.
   
- The new age is the instance/field value of the **me** object.
