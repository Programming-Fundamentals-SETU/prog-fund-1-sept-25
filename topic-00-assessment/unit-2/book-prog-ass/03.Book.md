# Book class

The responsibility for this class is to manage a single Book in the system.  



![](img/Book.png)

# Fields

There are four private fields in the Book class:

- *title*: The book title is maximum 10 characters.  When creating a new book, if the String is longer than 10 characters, you shoud truncate the string to the first 10 chars (**Hint** see String method *substring()* for a good  way to do this).   When updating (setter)*name*, you should only update if the length is less than or equal to 10.  

- *author*. The author is maximum 20 characters. Initialise by truncating to 20 chars. When updating (setter) *author*, you should only update if the length is less than or equal to 20.

- *isbn*. This the isbn number of the book. It should exactly be 13 characters. In the constructor, If the String is not 13 characters, it should be initialised to "0000000000000". When updating (setter) *isbn*, you should only update if the length is exactly 13.

- *onLoan*: A boolean value, set to false if the book is not currently on Loan, true otherwise. It should be initialised to false.

- *rating*: An integer between 0 and 5. It should be initialised to 0. When updating (setter) *rating*, you should only update if the value is between 0 and 5.
