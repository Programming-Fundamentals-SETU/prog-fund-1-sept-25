# Plan of attack and some key points


## Plan of Attack
The following is a suggest plan of attack to start and complete the assignment: 

1.	Create a new BlueJ Project in the usual way.

2.	Write the Book class as per the spec
3.	Identify the methods in the Library Class that are required to add a new Book and list all books
4.	Write these methods in the Library Class
5.	Identify the methods in the LibraryDriver class that are required to add books to the system and show the menu to the user.
6.	Write these methods in the LibraryDriver Class

At this point your code should be running, and you should be able to add new books to your system and you should be able to see the full menu but the menu items have no functionality yet.

7.	Working through the menu items, write the corresponding methods in your Library and LibraryDriver classes until all menu items are working correctly.
8.	Test your code!


## Some key points to remember when coding your assignment

- You **must** use the names given for the Classes and Methods; failure to do so will result in reduced marks.

- For all variables, methods and classes used, please adhere to the naming standards discussed in class.


- Don't forget that you can get IntelliJ to generate methods such as getters, setters, constructors and toString.  It is a good idea to generate these methods and then add the additional requirements (such as validation) manually.  This will free up some time for concentrating on other areas of the assignment. 

- There should be absolutely *NO* **System.out.println** or **ScannerInput** reads in any class except for the LibraryDriver class.  If you have any such interaction with the user in any class other than LibraryDriver, you will lose marks.  Instead, you should be returning information back to LibraryDriver to print it.  Or passing information read in LibraryDriver to other classes via method parameters.
