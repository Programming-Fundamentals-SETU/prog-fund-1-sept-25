# LIBRARY SYSTEM  Options

## Option 1 - `Add a new book`

Take in all the values for the book (apart from their ratings) and create and add this book  to the array of books. 


## Option 2 - `Borrow a book`

Firstly the user should be shown a list of all books in the library, then asked which book number  (isbn number) they wish to borrow.  This book's information should be updated to reflect this. (index number should be part of  the listing). 

## Option 3 - `Return a book`

Firstly the user should be shown a list of all books, then asked which book they wish to return(using index number). This books's information should be updated to reflect this. 

## Option 4 - `Rate a book`

Firstly the user should be shown a list of all books, then asked which book number they wish to rate. Then the user should be asked to enter a rating for the book.  This player's information should be updated to reflect this. 

## Option 5 - `List all books`

List all details (including index and  each rating) of all books.


## Option 6 - `List all  available books` 

List all details (including each rating) of all books that are currently not on loan. 




## Option 7 - `Show average rating`

Calculate and display the average rating of all books. Only books with a rating of at least 1 should be included in the calculation.


## Option 8 - `Show highest-rated book`

Calculate and display the book with the highest rating. If there are multiple books with the same highest rating, only one should be displayed.


 ## Option 9 - 'Exit`

This option exits the application.
