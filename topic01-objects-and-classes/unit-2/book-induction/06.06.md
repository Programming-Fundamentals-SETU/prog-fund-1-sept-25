# Console Drawing

Welcome to your very first bit of creative coding! Instead of just printing Hello World, let’s use Java to draw a picture in the console using keyboard symbols.

## Draw an Owl

- As before create a new Class called ConsoleArt and write in the following code:

~~~   
 public class ConsoleArt {
    public static void main(String[] args) {
        System.out.println("  ^  ^  ");
        System.out.println(" ( o o ) ");
        System.out.println("  (  -  )  ");
        System.out.println("   \\___/   ");
    }
}
~~~

**Notice how \\ is needed to print a single \.**

This prints a little owl face:

~~~
  ^  ^  
 ( o o ) 
  (  -  )  
   \___/   

~~~
