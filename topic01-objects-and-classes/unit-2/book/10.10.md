## Challenge Exercise 4 - Create a new Project

1. Create a new project called ShapesLab
2. Create 2 new Classes called Circle and Canvas (You can copy the code from the figures project)
3. Create two Circle objects on the object bench.
   - Name them circle1 and circle2.
4. Make both circles visible. 
   - Call the makeVisible() method on each object.
5. Invoke the correct method to make one bigger than the other
6. Invoke the correct method to move each vertically (circle1 to move to the top of the canvas and circle2 to the bottom)
7. Invoke the correct method to change each objects colour
8. Check the state of each objects. (Right-click on each object and choose Inspect)
9. Look at the values of its fields. Which fields change when you call moveHorizontal()?
