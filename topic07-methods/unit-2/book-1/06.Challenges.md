# Challenges 




## Challenge 1


**“Fortune Teller” Program**

**Description:**

- Create a small Java program with two classes:

  - FortuneTeller — contains all the methods.

  - Driver — contains main, creates a FortuneTeller object, and calls the methods.

- The program will:

  - Say a random fortune.

  - Give a personalised fortune based on the user’s name.

  - Predict the future based on the user’s age, and return a fun message.

 |  Method Name | Parameters |  Return Type | Description |
|----------|-----|--------|--------|
| `sayRandomFortune()`   | none       | void        | Prints a pre-written fortune .    | 
| `personalFortune(String name)` | name       | void        | Prints a silly or uplifting fortune that uses the person’s name.           |
| `futurePrediction(int age)`    | age        | String      | Returns a message predicting something about the person 10 years from now. |


## Driver (main) Flow
~~~
- Create a Scanner to get user input.
- Make a FortuneTeller object.
- Call the methods in this order:
- sayRandomFortune()
- Ask for name → personalFortune(name)
- Ask for age → futurePrediction(age) → print returned message
~~~

## FortuneTeller class:
~~~
    - sayRandomFortune:
        print fortune message.

    - personalFortune(name):
        Print a silly or uplifting message that includes the person's name.

    - futurePrediction(age):
        Add 10 to the age.
        Make a fun message about the future.
        Give that message back to whoever called the method.
~~~
