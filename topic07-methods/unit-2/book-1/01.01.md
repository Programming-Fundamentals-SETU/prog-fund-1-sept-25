# Understanding the Driver Class

The Driver class:

- Contains the main method — the starting point of the program.

- Creates objects from other classes.

- Calls methods on those objects to make things happen.

- Handles user input and output (e.g. using Scanner).

- Decides the sequence of actions in the program.

**The Driver does not usually contain the logic itself — it just coordinates it.**

These examples can all be written into the same Project, you should create a new project for this week.

## Methods with no parameter and no return

1. Create a Class called **MethodExamples**, and add the following method

~~~java
 public  void sayHello() {
        System.out.println("Hello!");
    }
~~~

2. In the same project, create a class called Driver, and add the following:

~~~java
       public static void main(String[] args) {
        MethodExamples me = new MethodExamples(); //create an object
        // 1 Call method with no parameters / no return
        me.sayHello();
       }

~~~
Why are you creating an object?  Ensure you understand this very important concept!
