# Methods with parameter and no return

1. In the Class called **MethodExamples**, and add the following method

~~~java
  public  void greet(String name, int age) {
        System.out.println("Hello, " + name + ", you are "
                + age + " years old.");
    }
~~~

2. Invoke (call) this method from your Driver, add the following to main

~~~java
       
me.greet("Mairead", 21);
~~~

What happens?  Can you improve this code and have the user enter the name instead of hardcoding it?
