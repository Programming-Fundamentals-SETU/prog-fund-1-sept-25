# Methods with parameter and return

1. In the Class called **MethodExamples**, and add the following method

~~~java
  public  int timesTwo(int a) {
        int num = a * 2;
        return num;
    }
~~~

2. Invoke (call) this method from your Driver, add the following to main

~~~java
       
 int sum = me.timesTwo(5);
 System.out.println("5 * 2 = " + sum);
~~~
