## Exercise 1 - Warm Welcome

Write a program that has:

A method called printWelcome() that prints a simple welcome message to the user.

The main method should call printWelcome() at the start of the program.

Example Output:
~~~
************************
 Welcome to My Program!
************************
~~~

**Extra:** Add another method, printGoodbye(), and call it at the end of the program.


## Exercise 2 - Rectangle Calculator

Write two methods:

- printArea(double width, double height) → calculates and prints the area of a rectangle.

- printPerimeter(double width, double height) → calculates and prints the perimeter.

Call both methods from main, passing appropriate values.

Example Call:
~~~
printArea(5.0, 3.0);
printPerimeter(5.0, 3.0);
~~~

Expected Output:
~~~
Area: 15.0
Perimeter: 16.0
~~~

**Extra** Ask the user to input width and height using Scanner and pass these to the methods.
