# Returning a value from a method

1. Create a Class called Driver (this will contain your main)
2. Create a class called ClassExamples (this will contain your methods)

You will use these 2 classes for all your examples in this lab

You are asked to write a method that will take in an int, cube it and return the answer (int)

In your ClassExamples class, add the follwoing code (remember you should always type it in rather than copy and paste)

~~~java
public class ClassExamples {


    int cubed(int num){
        return num * num * num;
    }
}

~~~

In your Driver class, you will create an object of  ClassExamples, this will allow you to invoke the methods


~~~java
 public static void main(String[] args) {
        ClassExamples ce = new ClassExamples();

        int numToBeCubed = 5;
        int cubedAns = ce.cubed(numToBeCubed);
        System.out.println(numToBeCubed + " cubed is " + cubedAns);

~~~
