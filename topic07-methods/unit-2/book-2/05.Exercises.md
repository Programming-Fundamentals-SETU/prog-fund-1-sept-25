# Exercise


## Exercise 1 - addNum()
Write a  method called addNum() that accepts 3 ints, adds them and returns the answer

The main method should call add(), pass it the 3 numbers and print the answer

Example Output:
~~~
Enter an 1st number : 
23
Enter an 2nd number : 
34
Enter an 3rd number : 
45
23 + 34 + 45 = 102
~~~

## Exercise 2 - overloading

Write a method called product() that accepts 3 ints, multiplies them and returns the answer

The main method should call product(), pass it the 3 numbers and print the answer

Example Output:
~~~

23 * 34 * 45 = 35190
~~~

## Exercise 3 - max()

Write a method called max() that accepts 3 ints, finds the largest and returns the answer

The main method should call max(), pass it the 3 numbers and print the answer

Example Output:
~~~
The max of 23 , 34 , 45 = 45
~~~

**You can assume that all numbers are different**
