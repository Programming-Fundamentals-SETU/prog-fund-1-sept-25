```java
public void printHello() {
```

| Term | Example | Meaning |
|------|----------|----------|

### **Q12. Fahrenheit → Celsius**

**Formula:**  
\[
C = (F - 32) \times \frac{5}{9}
\]

**Java method:**
```java
public double fahrenheitToCelsius(double fahrenheit) {
    return (fahrenheit - 32) * (5.0 / 9.0);
}
```

**Example call:**
```java
double c = fahrenheitToCelsius(98.6);
System.out.println("Celsius = " + c);
```
→ Output: `Celsius = 37.0`

### **Discussion Wrap-Up**

- Parameters keep methods general – no global variables.  
- Overloading adds flexibility and readability.  
- The Driver class separates logic from control flow.
